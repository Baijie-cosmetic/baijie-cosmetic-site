# Baijie Cosmetic Website

Static website package for GitHub Pages / Accio Work deployment.

## Files
- `index.html` — homepage
- `style.css` — responsive styling
- `script.js` — reserved for future interactions
- `assets/images/` — logo and product/category images

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch **main**, folder **root**.
5. Save and wait for GitHub Pages to publish.
